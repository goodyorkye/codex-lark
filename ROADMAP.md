# Roadmap

This roadmap describes direction, not a delivery promise.

## 0.1 — usable preview

- App Server task and approval control
- QR-created Feishu/Lark PersonalAgent
- foreground npm/npx launcher with terminal QR and status
- automated protocol and transport regressions

## 0.2 — low-friction daily use

- clearer reconnect and Desktop-version diagnostics
- pagination/search for large project and task sets
- optional background/service mode after the foreground workflow is stable

## 0.3 — compatibility confidence

- Desktop/App Server compatibility matrix
- recorded protocol fixtures across Desktop releases
- graceful IPC capability negotiation
- import/export UI with secret-safe defaults

## 1.0 — stable operator experience

- documented support window
- stable config migration policy
- accessibility and localization review
- external security review of callbacks, access control, and local IPC trust
